## 7b. AI Horde kudos-guard (priority-aware fallback)
Root cause: on a congested queue the old code submitted, polled ~14 min, then RESUBMITTED on timeout
without cancelling — each submit charges upfront kudos and the abandoned job still spends when it later
completes, so a slow queue multiplied spend (a scheduled Wilma gen burned ~330 kudos this way).
Fix (bot.py, covers main + Wilma via generate_image): HORDE_MAX_WAIT_S (env, default 150s). On the first
status poll, if wait_time > threshold -> DELETE the job (cancel refunds upfront kudos while queued) -> go
straight to fallback, NO resubmit (image raises HordeQueueTooLong caught non-retryably; text returns "").
On polling timeout also cancel + fall back. queue_position is kudos-relative (= priority); wait_time is the
estimated seconds. Low priority -> quick fallback at ~0 net kudos; trusted + high kudos -> short wait ->
Horde stays default, fallbacks preserved. Commit bfbc6efd.
Verified: mock tests (image 3 scenarios, text 2) — long wait->bail+1 cancel, short-wait-stall->timeout+1
cancel, done-first-poll->success+0 cancel. Read-only live probe: installed key = iyeque#606751, 120 kudos
usable, trusted=False (worker's ~11k kudos pending until trusted); only Juggernaut XL + DreamShaper XL
online at probe time.

## 7i. Main LinkedIn truncation root cause + pillar-aware caption lenses
Evidence: bundle 370 LinkedIn caption was 2,311 chars ending mid-sentence ("imperfection in"),
with literal "### CTA:" and "#LinkedIn" scaffolding in the body. Two root causes:
(1) `_PLATFORM_CHAR_LIMITS["linkedin"]` and brand_guardian `PLATFORM_LIMITS["linkedin"]` were 3000
though the brand brief says 1800 soft / 2000 hard; (2) `is_cropped_or_truncated()` only flagged an
incomplete ending when length < 50% of the limit, so 2311 > 1500 passed. A hard-cap "..." also
counted as terminal punctuation.
Fixes: limits now 2000 in both places; `is_cropped_or_truncated()` judges the ENDING (strips
trailing hashtag/CTA lines, flags markdown/CTA scaffolding, flags trailing "..." near the limit,
flags a cut ending on a preposition/article); `clean_caption_formatting()` strips platform-tag
artifacts (#LinkedIn et al) and is now applied to captions on BOTH the agent-bundle and
non-agent paths.
Pillar quality: the pillar only drove image prompts and hashtags, so all pillars read the same.
Added `PILLAR_CAPTION_LENSES` (micro_philosophy/nature_metaphor/systems_psychology/author_voice/quote)
and a `lens=` arg to `openrouter_captions.tailor()`, passed from `_build_deterministic_caption()`.
Verified: 33 passed + 9 subtests. Commit 974c5d1a (rebasing onto remote quote-state commit before push).
